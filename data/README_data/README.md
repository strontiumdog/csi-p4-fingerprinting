# Data availability

Raw CSI capture files are not committed to this repository owing to size.

The extraction scripts in `tools/extraction/` operate on:
- FeitCSI `.dat` files
- PicoScenes `.csi` files (format version 0x315)

Place capture files in a local folder and pass the folder path to the
extraction scripts. See `docs/capture_protocol.md` for naming conventions
and capture settings.

Capture data supporting the published results is available from the authors
on reasonable request.
